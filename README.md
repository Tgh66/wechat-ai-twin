# 微信 AI 数字分身工作台（WeChat AI Twin）

基于**你自己的微信聊天记录**的本地 AI 工作台：数据统计、情感分析、双人报告与"数字分身"对话，全部数据在本机处理，**零 API 费用**。

> v1.1 采用 **Go 语言全量重构**：单个免安装 exe（约 17MB）、零运行时依赖、毫秒级查询、自动弹出浏览器、关闭浏览器自动停止服务。

---

## ✨ 功能总览（整合 5 个开源项目能力）

### 1. 总览分析（8 张图表 + 10 指标卡）
- 消息总数 / 我发送 / 对方发送 / 占比 / 活跃天数 / 日均 / 会话数 / 平均句长
- 消息最多的一天、最晚互动时间
- 消息类型构成（文本/图片/语音/视频/表情/红包/转账/通话…）
- 24 小时活跃分布、星期活跃分布
- 月度消息趋势（近 24 个月）
- 我的高频词 / 对方高频词 / 消息量词云 / 表情使用排行

### 2. 情感分析（12 张图表 + 10 指标卡）⭐ 重点完善
- 情感倾向度（-100 ~ +100）、积极/消极/中性消息数、强烈情绪占比
- 双方情感分、情绪波动指数、**亲密度评分（0-100）**
- 情感随时间变化（逐月均值折线）
- **近 30 天情感热力图（日期 × 时段）**
- **七类情绪分布**（乐/好/怒/哀/惧/恶/惊，雷达 + 饼图，基于大连理工情感词典）
- 高频情绪词、情绪词云、情感强度分布
- 双方情感对比雷达、双方消息量对比、各时段情感均值

### 3. 记录分析
- 关键词全文搜索（带上下文高亮、翻页）
- 导出 JSON

### 4. 双人报告
- 亲密度、互动节奏（谁先开口）、深夜互动量、会话跨度、情绪峰值
- 消息序列构成、昼夜互动对比、情感波动指数
- 双方关键词横向对比

### 5. 数字分身（AI 对话）
- 与你微调的本地模型对话（Qwen 系列，基于你的聊天记录训练）
- 支持 6GB 显存笔记本（Qwen3-4B 8bit 量化推理）

### 6. 数据接入
- **自动发现微信目录**：注册表 + 默认路径 + 全盘扫描 `xwechat_files` / `WeChat Files`
- 支持 JSONL 聊天记录导入（自动建索引，152 万条秒级加载）
- 增量复用已有索引（重启秒开）

### 7. 训练（界面全流程）⭐ 新增
- 任意会话 → 训练"我"或"对方"的数字分身（如联系人A的说话风格）
- 模型：本地扫描 + ModelScope 镜像目录下载 + 手动路径导入
- GPU 实时监控（显存/利用率）自动判断能否训练
- 进度条 + 实时日志 + 训练完成自动启动推理

## 🚀 快速开始

### 方式一：直接运行（推荐）
1. 下载 Release 中的 `WeChatTwin-win64.zip`，解压到任意目录（如 `D:\WeChatTwin`）
2. 双击 `WeChatTwin.exe`
3. 浏览器自动打开工作台（关闭浏览器后服务自动停止）

### 方式二：源码构建
```bash
# 需要 Go 1.24+
go mod tidy
go build -o WeChatTwin.exe .
./WeChatTwin.exe
```

### 数据准备（二选一）
- **自动**：把微信聊天记录导出为 JSONL 放入 `data\` 目录，程序启动自动建索引
- **手动**：工作台左下角「自动搜索」→ 自动发现微信目录；或「导入记录」手动指定 JSONL 路径

> JSONL 格式：每行 `{"name":"联系人","is_self":true,"ts":1700000000,"type":"文本","content":"你好"}`

## 🤖 数字分身（界面内"从零训练"全流程）

打开工作台 → **「训练」标签页**，按顺序操作，全程图形化，无需命令行：

1. **GPU 状态卡**：实时显示显卡型号 / 总显存 / 已用 / 可用 / 利用率，并自动判断「能否开始训练」
2. **① 选择目标会话**：下拉选择任意聊天对象（如「联系人A」，数十万条）
3. **② 选择训练谁**：
   - 「我」→ 训练模仿**你自己**说话方式的分身（对方消息为输入，你的回复为学习目标）
   - 「对方」→ 训练模仿**对方**的分身（你的消息为输入，对方回复为学习目标）
4. **③ 选择基础模型**：
   - 本地模型列表自动扫描（`models\` 目录，含已下载的 Qwen3-4B）
   - **镜像模型目录**：内置 ModelScope 官方源（国内直连）的 Qwen 系列清单，点「下载选中」即后台下载
   - 或手动粘贴本地模型目录路径（含 config.json）
5. **④ 训练参数**：epochs / 样本上限 / 学习率 / 推理端口
6. **🚀 开始训练**：进度条显示 阶段 → step/total → loss，日志实时滚动；可随时「停止」
7. **训练完成后自动合并 LoRA → 自动启动推理服务**，「数字分身」页立即可用新模型对话

> 训练底层：QLoRA 4bit 微调（PEFT + bitsandbytes），RTX 3060 6GB 显存可跑 Qwen3-4B（约 2-4 小时/epoch 1.5 万样本）。训练全程本地、零 API 费用。

## 🗂 技术架构

| 组件 | 选型 | 说明 |
|---|---|---|
| 主程序 | **Go 1.24** | 单静态 exe、标准库 HTTP、无运行时依赖 |
| 数据库 | **SQLite**（modernc.org/sqlite 纯 Go 驱动） | 无 CGO、152 万条毫秒级聚合 |
| 前端 | 原生 HTML + ECharts 5 | 本地文件、离线可用、30+ 图表 |
| 浏览器 | 默认浏览器 | 启动自动打开，关闭自动停止服务 |
| 训练/推理 | Python + PyTorch | QLoRA 微调、8bit 推理（6GB 显存可跑） |

### 为什么用 Go 重构？
- **零依赖**：单个 exe 免安装，无需 Python 运行时即可运行分析功能
- **性能**：37 万条消息统计从 Python 版 ~27s 优化到 **1.5s**
- **简洁**：编译型语言，内存占用低（SQLite 流式聚合，不做全量载入）

## 🚀 便捷配置教程（豆包工作一键本地部署）

> 适用：换新电脑 / 别人机器 / 全新环境，不想手工装 Python 依赖。**程序本身会自动配置环境**（见 v1.1.4），本教程是"连双击都不用，全交给豆包"的快捷方式。

### 方式 A：只用程序（最简）
1. 下载 Release 里的 `WeChatTwin-win64.zip`，解压到任意目录
2. 双击 `WeChatTwin.exe`，浏览器自动打开 `http://127.0.0.1:7860/`
3. 确认微信已登录运行 → 数据页点「🔓 自动解密微信数据库」
4. **无需任何环境配置**：安装包内置 Python 3.11 运行时 + 解密引擎全套离线依赖（runtime/ + wheels/ 目录），**不装系统 Python、不联网也能自动解密**
5. 进度条走完 = 聊天记录已全量导入（数据页/记录分析即可使用）

### 方式 B：提示词一键部署（豆包工作·本地任务）
把下面整段提示词复制，发给「豆包工作」→ 选择**本地任务**执行，即可自动完成：拉取仓库 → 配置环境（离线优先）→ 全量导出聊天记录 → 启动服务。

```text
【任务：微信 AI 数字分身工作台 · 从 GitHub 拉取仓库并一键配置 + 导出聊天记录 + 启动服务】
仓库：https://github.com/Tgh66/wechat-ai-twin（Go 全量重构版，zip 自带离线依赖包）

请依次完成以下步骤，全程用简体中文汇报进度，不要省略任何一步：

1. 从 GitHub 下载/克隆仓库到本地（推荐下载 Release 最新 zip 解压；或 git clone，国内网络不通可先用镜像加速）
2. 自动配置 Python 解密环境（优先离线，全程不依赖外网）：
   - 若项目 venv\Scripts\python.exe 已存在且能 import wechatauto，直接使用；
   - 否则用系统 Python 创建 venv（优先 py -3.11，与离线包匹配），执行离线安装：
     <venv>\Scripts\python.exe -m pip install --no-index --find-links wheels\ --no-build-isolation --no-deps wechatauto_replica cryptography cffi pycparser pywin32 winsdk uiautomation zstandard comtypes colorama psutil pyperclip pymsgbox pyautogui pyscreeze pygetwindow pyrect pytweening mouseinfo pillow
     并先装 wheel 包（构建需要）：
     <venv>\Scripts\python.exe -m pip install --no-index --find-links wheels\ wheel
   - 若离线安装失败（Python 版本不是 3.11 等），改用国内镜像在线安装：
     <venv>\Scripts\python.exe -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple wechatauto-replica cryptography
   - 验证：<venv>\Scripts\python.exe -c "import wechatauto" 无报错
3. 确认微信桌面版已登录并保持运行（Weixin.exe / WeChat.exe，用于从进程内存提取数据库密钥）
4. 全量导出聊天记录：
   <venv>\Scripts\python.exe scripts\decrypt_wechat.py --out data\wechat_decrypt.jsonl
   等待脚本输出 [DONE]，检查 data\wechat_decrypt.jsonl 已生成且非空（微信 4.0 约百万条量级）
5. 启动服务：运行 WeChatTwin.exe（或 go build 后运行），浏览器自动打开 http://127.0.0.1:7860/
6. 在界面数据页点「🔓 自动解密微信数据库」把导出合并进索引（或直接确认索引已更新），
   并在「记录分析」搜索验证能找到历史消息

硬性约束：
- 严禁上传/推送/外发 data\、models\、*.jsonl、*.db 等任何用户聊天数据（隐私红线）
- 不要删除、覆盖或移动用户已有的 data\ 与 models\ 目录及文件
- 解密必须在微信运行状态下进行；若微信未运行，明确提示用户先登录微信
- 每一步完成后报告结果，失败则说明原因和修复方案，不要静默跳过
```
