# 🤖 微信 AI 数字分身工作台 (WeChat AI Twin Workbench)

> 用你自己的微信聊天记录，训练一个"说话像你"的本地 AI 数字分身。
> 自动发现微信数据 → 导出聊天记录 → 智能清洗 → LoRA/QLoRA 微调 → 多消息连发对话 → 情感分析 → 单会话聊天记录分析。
> **全程本地运行，聊天数据不出本机，零 API 费用。**

## ✨ 功能总览

| 模块 | 功能 |
| --- | --- |
| ① 数据发现 | 自动搜索微信数据（注册表 / 默认目录 / 各磁盘 `xwechat_files` 索引），支持手动指定；检测微信运行状态与管理员权限 |
| ② 导出聊天记录 | 全部会话 / 关键词筛选 / 单个会话；自动识别"自己"的发言（wxid）；流式导出不占内存 |
| ③ 数据清洗 | **会话级白名单**（自动剔除客服/接单/群聊/商家/文件传输等污染源）+ 消息级过滤（丢弃 URL、超长粘贴、XML 消息、垃圾短句）；**多消息连发结构**（模型学会像微信一样一次回 2~5 条） |
| ④ 微调训练 | **自动检测显卡并推荐模型**（6GB 显存可跑 Qwen3-4B QLoRA）；实时 loss / 速度 / 显存占用 / 进度条；loss masking（只学"你"的回复） |
| ⑤ 对话（多消息） | 加载微调模型；**一次回复 2~5 条微信消息**（气泡连发）；可调人设 / 温度；自动识别本地所有已训练模型下拉切换 |
| ⑥ 情感分析 | 情感倾向度（-100~+100，规则评分，**无需模型**）；**数字分身读心**（用你的模型分析对话里的真实情绪和对对方的感受）；可自由下载情感小模型 |
| ⑦ 聊天记录分析 | 指定会话：总条数 / 自己·对方占比 / 时间跨度 / 情感倾向 / 高频词 / 最近消息回放（流式读取，大文件不爆内存） |

## 🖥️ 两种使用方式

### 方式一：全功能单页工作台（推荐）

```bash
python twin_app.py
# 打开 http://127.0.0.1:7860
```

一个页面包含 **对话 + 情感分析 + 聊天记录分析** 三个标签页，自动识别 `models/` 下所有已训练模型，可切换。

### 方式二：图形化工作流应用

```bash
python app.py
# 打开 http://127.0.0.1:7860（6 个功能页：发现→导出→清洗→训练→对话→统计）
```

适合完成"从数据到模型"的完整流程。

## 📦 安装

### 环境要求
- Windows 10/11（微信电脑版 4.x，**导出时需要微信已登录运行**）
- Python 3.10+
- NVIDIA 显卡（可选，推荐，用于 GPU 训练）

### 安装步骤

```bash
# 1. 安装 PyTorch（CUDA 版）
pip install torch --index-url https://download.pytorch.org/whl/cu126

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动（方式一）
python twin_app.py
```

> Windows 一键启动：双击 **`run.bat`**（自动请求管理员权限 + 安装依赖）。
> 国内网络：模型下载自动走 ModelScope 镜像（`modelscope`），无需科学上网。

## 🚀 使用流程（新手向）

1. **登录微信电脑版**（必须运行中，程序需要从微信进程内存提取数据库密钥）
2. **发现数据**：`python app.py` → ①数据发现 → 自动搜索 → 连接数据库
3. **导出**：②导出聊天记录 → 全部导出（或按会话筛选）
4. **清洗**：③构建训练集（默认参数已针对日常对话优化）
5. **训练**：④刷新显卡 → 自动推荐模型（6GB 显存 → Qwen3-4B）→ 开始训练 → 合并模型
6. **使用**：`python twin_app.py` → 自动加载最新合并模型 → 对话 / 情感 / 分析

## 🧠 技术说明

### 模型推荐（按显存）

| 显卡显存 | 推荐模型 | 训练方式 | 说明 |
| --- | --- | --- | --- |
| 6GB | **Qwen3-4B** | QLoRA (4bit nf4) | 性价比最高，效果明显好于 2B |
| 6GB | Qwen3.5-2B | LoRA (bf16) | 训练最快 |
| 4GB | Qwen2.5-1.5B | LoRA (bf16) | 轻量 |
| 2GB | Qwen3-0.6B | LoRA (bf16) | 极限轻量 |

- **微信数据读取**：基于 `wechatauto`，自动从运行中的微信进程内存提取 SQLCipher 密钥，无需密码、无需越狱。
- **训练**：ChatML 模板 + loss masking（只对"你的回复"计算损失，模型不会学复读标签）+ 长回复优先 + 会话平衡。
- **数据清洗核心**：剔除客服/接单/群聊/商家会话与文件传输会话；丢弃 URL、超长粘贴（>150 字）、XML 消息（语音/图片/文件描述）；合并连续发言为"多消息连发"训练目标。
- **推理**：`eos_token_id=<|im_end|>` 显式指定，回复按行拆分为多条微信消息气泡。

## 🛠 常见问题

- **找不到微信数据目录？** 确认微信已登录运行；数据根目录是包含 `wxid_*` 账号目录的那一层（如 `E:\xwechat_files`）；无权限时以管理员身份运行。
- **导出报错？** 微信必须处于运行状态（密钥在进程内存中）。
- **模型回复太短 / 答非所问？** 用 v3 清洗（默认开启"会话白名单 + 长回复优先"）重新构建训练集；换 Qwen3-4B 重训效果提升明显。
- **模型乱说话 / 冒出网址？** 旧版数据混入了客服/长文粘贴/链接，重新清洗（会剔除 URL 与超长消息）后重训即可。
- **想一次回多条消息？** v3 训练集已建立多消息连发结构，生成时会按微信风格返回 2~5 条短消息。
- **下载模型太慢？** 已内置 ModelScope 国内镜像，自动加速。
