# 🤖 微信 AI 数字分身工作台 (WeChat AI Twin Workbench)

> 用你自己的微信聊天记录，训练一个"说话像你"的本地 AI 数字分身，并一键完成从数据发现、导出、清洗、微调、对话到情感分析的完整闭环。**全程本地运行，聊天数据不出本机。**

---

## ✨ 功能总览

| 模块 | 功能 |
| --- | --- |
| ① 数据发现 | 自动搜索微信数据（注册表 + 默认目录 + 各磁盘 `xwechat_files` 索引扫描），找不到可手动指定；自动检测微信运行状态与管理权限 |
| ② 导出聊天记录 | 列出全部会话（名称 / wxid / 消息数），支持**全部导出 / 关键词筛选 / 单个会话**，自动识别"自己"的发言 |
| ③ 数据清洗 | 过滤表情、图片、系统消息等噪声；控制句子长度与训练样本量；**长回复优先**解决"句子太短"；会话平衡防止大群独霸 |
| ④ 微调训练 | **自动检测显卡（显存/占用）并推荐模型**；可从 HuggingFace 下载模型；LoRA 微调（6GB 显存可跑 2B 模型）；实时显示 **loss、训练速度、显存占用与进度条** |
| ⑤ 对话 | 加载微调后的模型，模拟你的说话风格与好友聊天；可调温度 / 回复长度 / 人设 prompt |
| ⑥ 统计与情感 | 消息条数、自己/对方占比、会话排行、24 小时活跃分布、月度趋势、高频词、回复速度；**情感倾向度评分**、**数字分身"读心"**（分析你当时对对方的感受）、**情感小模型**（可自由下载） |

## 📦 安装

### 环境要求
- Windows 10/11（微信电脑版 4.x，微信需**已登录运行**）
- Python 3.10+
- NVIDIA 显卡（可选，用于 GPU 训练；无显卡可用 CPU，速度较慢）

### 安装步骤

```bash
# 1. 安装 PyTorch（CUDA 版，有 NVIDIA 显卡时）
pip install torch --index-url https://download.pytorch.org/whl/cu126

# 2. 安装项目依赖
pip install -r requirements.txt

# 3. 启动
python app.py
# 浏览器会自动打开 http://127.0.0.1:7860
```

> Windows 用户也可以直接双击 **`run.bat`**（会自动请求管理员权限并安装依赖）。

## 🚀 使用流程

1. **数据发现** → 点击"自动搜索"，找到微信数据根目录（如 `E:\xwechat_files`）→ 点击"连接数据库"（需要微信在运行）
2. **导出** → 选择导出范围（如"全部会话"）→ 开始导出，等待完成
3. **清洗** → 按需调整最短/最长句子长度、样本量 → 构建训练集
4. **训练** → 点击"刷新显卡信息"查看显卡与显存 → "自动推荐模型"（或手动输入模型名下载）→ 设置训练参数 → 开始训练（页面显示 loss / 速度 / 显存 / 进度条）→ 训练完成后"合并模型"
5. **对话** → 填入合并模型目录 → 加载模型 → 和你的数字分身聊天
6. **分析** → 加载导出文件 → 查看统计图表、高频词、情感倾向；可用数字分身"读心"或下载情感小模型

## 🧠 技术说明

- **微信数据读取**：基于 `wechatauto`，自动从运行中的微信进程内存提取数据库密钥（SQLCipher 4 加密），无需密码、无需越狱。
- **模型微调**：Qwen3.5-2B / Qwen2.5-1.5B 等 ChatML 模型 + **LoRA**（`all-linear` target，r=16, alpha=32）+ bf16 + 8-bit AdamW，6GB 显存可训练 2B 模型。训练只对"你的回复"计算损失（loss masking），避免模型复读标签。
- **训练集构建**：以"对方消息 → 你的回复"为单元，保留多轮上下文；长回复优先、会话平衡、按会话分层切分训练/验证集。
- **情感分析**：内置规则评分（正面/负面词频归一化到 -100~100）；可选 HuggingFace 情感分类小模型；可用微调后的数字分身模型做开放式"读心"分析。

## 🛠 常见问题

- **找不到微信数据目录？** 确认微信已登录运行；数据根目录是包含 `wxid_*` 账号目录的那一层（如 `E:\xwechat_files`）。若目录无权限，请以管理员身份运行。
- **导出报错？** 微信必须处于运行状态（密钥在进程内存中）。
- **训练太慢？** 降低样本量、使用更小模型、或使用 NVIDIA 显卡（显存不足时 LoRA + 梯度累积可在 6GB 显存运行 2B 模型）。
- **数字分身回复太短？** 在"数据清洗"页开启"长回复优先"并适当提高长回复阈值；训练轮数可适当增加到 2-3。
