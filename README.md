# 微信 AI 数字分身工作台（WeChat AI Twin）

基于**你自己的微信聊天记录**的本地 AI 工作台：数据统计、情感分析、双人报告与"数字分身"对话，全部数据在本机处理，**零 API 费用**。

> v1.1 采用 **Go 语言全量重构**：单个免安装 exe（约 17MB）、零运行时依赖、毫秒级查询、自动弹出浏览器、关闭浏览器自动停止服务。

---

## ✨ 功能总览（整合 5 个开源项目能力）

### 1. 总览分析（8 张图表 + 10 指标卡）
- 消息总数 / 我发送 / 对方发送 / 占比 / 活跃天数 / 日均 / 会话数 / 平均句长
- 消息最多的一天、最晚互动时间
- 消息类型构成（文本/图片/语音/视频/表情/红包/转账/通话…）
- 24 小时活跃分布、星期活跃分布
- 月度消息趋势（近 24 个月）
- 我的高频词 / 对方高频词 / 消息量词云 / 表情使用排行

### 2. 情感分析（12 张图表 + 10 指标卡）⭐ 重点完善
- 情感倾向度（-100 ~ +100）、积极/消极/中性消息数、强烈情绪占比
- 双方情感分、情绪波动指数、**亲密度评分（0-100）**
- 情感随时间变化（逐月均值折线）
- **近 30 天情感热力图（日期 × 时段）**
- **七类情绪分布**（乐/好/怒/哀/惧/恶/惊，雷达 + 饼图，基于大连理工情感词典）
- 高频情绪词、情绪词云、情感强度分布
- 双方情感对比雷达、双方消息量对比、各时段情感均值

### 3. 记录分析
- 关键词全文搜索（带上下文高亮、翻页）
- 导出 JSON

### 4. 双人报告
- 亲密度、互动节奏（谁先开口）、深夜互动量、会话跨度、情绪峰值
- 消息序列构成、昼夜互动对比、情感波动指数
- 双方关键词横向对比

### 5. 数字分身（AI 对话）
- 与你微调的本地模型对话（Qwen 系列，基于你的聊天记录训练）
- 支持 6GB 显存笔记本（Qwen3-4B 8bit 量化推理）

### 6. 数据接入
- **自动发现微信目录**：注册表 + 默认路径 + 全盘扫描 `xwechat_files` / `WeChat Files`
- 支持 JSONL 聊天记录导入（自动建索引，152 万条秒级加载）
- 增量复用已有索引（重启秒开）

## 🚀 快速开始

### 方式一：直接运行（推荐）
1. 下载 Release 中的 `WeChatTwin-win64.zip`，解压到任意目录（如 `D:\WeChatTwin`）
2. 双击 `WeChatTwin.exe`
3. 浏览器自动打开工作台（关闭浏览器后服务自动停止）

### 方式二：源码构建
```bash
# 需要 Go 1.24+
go mod tidy
go build -o WeChatTwin.exe .
./WeChatTwin.exe
```

### 数据准备（二选一）
- **自动**：把微信聊天记录导出为 JSONL 放入 `data\` 目录，程序启动自动建索引
- **手动**：工作台左下角「自动搜索」→ 自动发现微信目录；或「导入记录」手动指定 JSONL 路径

> JSONL 格式：每行 `{"name":"联系人","is_self":true,"ts":1700000000,"type":"文本","content":"你好"}`

## 🤖 数字分身（训练自己的 AI）

数字分身需要先基于你的聊天记录微调模型（Python 环境，一次性工作）：

```bash
# 1. 构建训练集（从聊天记录生成对话对）
python scripts/build_dataset.py data/chat_messages.jsonl data/train.jsonl

# 2. 微调（6GB 显存可用 Qwen3-4B + LoRA / Qwen3-4B 8bit）
python scripts/train_lora.py --model Qwen3-4B --data data/train.jsonl

# 3. 启动推理服务（工作台「数字分身」页自动连接）
python scripts/serve_model.py --model models/Qwen3-4B-wx-merged --port 5000
```

推理服务启动后，回到工作台「数字分身」页即可对话（端口自动探测 5000/8000/8001/5001）。

## 🗂 技术架构

| 组件 | 选型 | 说明 |
|---|---|---|
| 主程序 | **Go 1.24** | 单静态 exe、标准库 HTTP、无运行时依赖 |
| 数据库 | **SQLite**（modernc.org/sqlite 纯 Go 驱动） | 无 CGO、152 万条毫秒级聚合 |
| 前端 | 原生 HTML + ECharts 5 | 本地文件、离线可用、30+ 图表 |
| 浏览器 | 默认浏览器 | 启动自动打开，关闭自动停止服务 |
| 训练/推理 | Python + PyTorch | QLoRA 微调、8bit 推理（6GB 显存可跑） |

### 为什么用 Go 重构？
- **零依赖**：单个 exe 免安装，无需 Python 运行时即可运行分析功能
- **性能**：37 万条消息统计从 Python 版 ~27s 优化到 **1.5s**
- **简洁**：编译型语言，内存占用低（SQLite 流式聚合，不做全量载入）
